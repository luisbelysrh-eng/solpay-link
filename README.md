# solpay-link
Decentralized payment gateway &amp; non-custodial escrow protocol on Solana powered by Solana Pay &amp; Blinks.
## Overview
SolPay Link allows traditional e-commerce merchants and digital content creators to accept instant stablecoin payments (USDC) with near-zero transaction fees. 

By leveraging Solana Pay and Solana Blinks/Actions, SolPay Link transforms any standard internet URL or social media post into an interactive, secure point-of-sale terminal directly within social feeds like X (Twitter).
